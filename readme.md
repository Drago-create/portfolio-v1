# portfolio-v1

A basic personal portfolio built with plain HTML and CSS.

## Files

- `index.html` — page markup
- `styles.css` — all styling

## View it

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Customize

Replace the placeholder name, email, project cards, and social links in `index.html`.
Colors live in the `:root` variables at the top of `styles.css`.
